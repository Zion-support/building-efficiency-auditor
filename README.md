## What it does
Turns BMS/IoT data into ranked retrofit recommendations with savings estimates, compliance scoring and audit-ready reports. Validates savings against [Energy Consumption Forecaster](https://github.com/Zion-support/energy-consumption-forecaster) baselines and feeds [Grid Demand Balancer](https://github.com/Zion-support/grid-demand-balancer) and [Solar ROI Optimizer](https://github.com/Zion-support/solar-roi-optimizer) planning.

## Key features
- Automated audit workflows (ASHRAE-style levels I–III)
- Ranked retrofit list with payback and compliance scoring
- BMS/IoT connectors, dashboards, PDF audit reports
